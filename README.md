## Ishga tushirish

1. Node.js 20+ o‘rnating.
2. `npm install`
3. `.env.example` ni `.env` qilib nusxalang.
4. `.env` ichiga `OPENAI_API_KEY` yozing.
5. `npm start`
6. `http://localhost:3000`

API kalitni hech qachon frontend JavaScript ichiga yozmang.
